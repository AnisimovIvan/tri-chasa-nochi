# 3 часа ночи

Мобильная игра на Godot 4.7 в духе Suika Game про навязчивые мысли перед сном.

## Идея

Три часа ночи, а в голове мысли. Одинаковые мысли сливаются в мысли побольше:
«хм» → «утюг?» → … → «ЭКЗИСТЕНЦИАЛЬНЫЙ УЖАС». Если мысли переполнят голову, ты проснулся.
Счёт — это минуты сна, часы идут от 03:00. Цель — продержаться до будильника в 07:00.

## Механики

- **Слияние (Suika).** Одинаковые мысли сливаются в мысль следующего уровня. Всего 11 уровней.
  Две мысли последнего уровня гасят друг друга и дают «глубокий сон» (+100).
- **Дыхание.** Если зажать кнопку «дыши», время замедляется, а самые мелкие мысли растворяются.
  Запас дыхания ограничен и медленно восстанавливается.
- **Цепочки.** Слияния подряд (меньше 1,1 с между ними) умножают очки.
- **Проигрыш.** Если мысль держится выше пунктирной линии дольше 2,3 с, ты проснулся.

## Устройство проекта

- `scripts/thought_data.gd` — уровни мыслей: размеры, цвета, фразы, очки.
- `scripts/thought.gd` — одна мысль: физическое тело, отрисовка лица и текста, поиск близнеца.
- `scripts/main.gd` — игровой цикл, ввод, дыхание, счёт, интерфейс, эффекты.
- `scripts/sfx.gd` — звуки, которые генерируются в коде (без файлов).

Вся графика рисуется кодом через `_draw()`, без внешних ассетов.

## Запуск

```bash
/Applications/Godot.app/Contents/MacOS/Godot --path . 
```

Веб-сборка:

```bash
/Applications/Godot.app/Contents/MacOS/Godot --headless --path . --export-release Web build/web/index.html
```

Автотест с ботом и скриншотом: `-- --autoplay=20 --shot=/путь/shot.png`.
